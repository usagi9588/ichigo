# Project Collaboration Rules

- Read `progress.md` before starting work and follow its latest plan and task status.
- Update `progress.md` as soon as each task is completed: check off the relevant task and add tasks, verification results, or unresolved issues as needed. Do not mark incomplete or unverified work as complete.
- After each task, append one `Summary` line to the bottom of `progress.md` describing what was done. Keep existing summaries. Format: `- YYYY-MM-DD Summary: Work completed and verification result.`

- When the user asks to apply for a job in Ichigo, recapture a screenshot, or record an application result, read and use `skills/apply-job/SKILL.md`. Project development work does not trigger the application workflow.
